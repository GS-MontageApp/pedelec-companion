# Pedelec Companion

Mobile-first Web-App für Pedelec-Ladeassistenz und spätere Reichweiten-/Tourenplanung.

## Aktueller Stand
Dieses Repository enthält die fachliche Grundlage für den ersten **Look-and-Feel-Prototyp**. Die Implementierung durch Codex steht noch aus.

- [Produktkonzept](docs/PRODUCT_SPEC.md)
- [Codex-Arbeitsanweisungen](AGENTS.md)

## Geplanter Stack
React + TypeScript + Vite + Tailwind CSS + Lucide Icons. Später IndexedDB mit Dexie und PWA-Unterstützung.

## Codex – erster Auftrag
Lies zuerst `AGENTS.md` und `docs/PRODUCT_SPEC.md`. Erstelle anschließend den lauffähigen UI-Prototyp entsprechend den Akzeptanzkriterien. Führe die vorgesehenen Prüfungen aus und dokumentiere das Ergebnis. Arbeite auf dem Entwicklungsbranch `codex/ui-prototyp`; ändere `main` nicht direkt.
